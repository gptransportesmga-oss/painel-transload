Painel de Viagens

🌡 °C

Abra o Ca2Track, selecione e copie a tabela (Placa, Data/Hora, Km/h, Posição, Referência e Temperaturas) e cole abaixo (Ctrl+V). Os veículos são casados automaticamente pela placa. Atalho: Ctrl+Enter para atualizar.

Entregas por viagem. Na BSoft: no CT-e filtre pela placa e pegue o Nº da viagem (ex: 1745); cole esse número em NF-e Pré-Cadastradas e veja as notas (Destinatário + Endereço). Cada endereço distinto = 1 entrega (notas do mesmo endereço são somadas). Cole aqui uma linha por entrega, no formato PLACA | Cliente | Cidade/UF | NFs — ou, pra ajudar o painel a detectar sozinho quando o caminhão chegou (mesmo com nome fantasia diferente do nome na nota), inclua também a rua: PLACA | Cliente | Cidade/UF | Rua | NFs. Se o caminhão não tiver NF na BSoft (provável fim de viagem), use PLACA | FIM.




⚙ Configurações

Antes de cadastrar: os usuários ficam guardados neste computador. Se a equipe usa máquinas diferentes, crie o usuário e depois use Dados → Exportar backup para levar a lista para os outros computadores. E lembre: esta tranca impede o acesso casual, mas quem entende de informática consegue contorná-la — não guarde aqui nada que precise de sigilo real.

Quadro compartilhado

Com isto ligado, todo mundo vê o mesmo quadro: o que uma pessoa marcar aparece para as outras em poucos segundos — entregas, status, ocorrências e o rastreio. Sem isto, cada computador tem o seu.

Cole abaixo os dois dados do seu projeto no Supabase (o serviço gratuito que guarda o quadro). Você encontra em Project Settings → API: o Project URL e a chave anon public. A chave anon é feita para ficar no navegador — não é uma senha.
Como criar o banco (passo a passo)
1. Crie uma conta em supabase.com e um projeto novo (grátis).
2. No menu SQL Editor, cole e execute: 
create table painel (

  id text primary key,

  dados jsonb,

  atualizado_em timestamptz default now(),

  por text

);

alter table painel enable row level security;

create policy "acesso do painel" on painel

  for all using (true) with check (true);
3. Vá em Project Settings → API, copie o Project URL e a chave anon public.
4. Cole aqui em cima e clique em Testar e ativar.

Conexão com o CA2Track (API Transrisco)

Com a API, o painel busca posição e temperatura sozinho, sem copiar e colar. Use o mesmo usuário e senha com que você entra no Ca2Track.

Faça o teste antes de ligar o automático. O navegador só deixa esta página conversar com o servidor do CA2Track se o servidor autorizar (uma regra chamada CORS). Se o teste falhar por causa disso, não é senha errada — é preciso pedir ao suporte do CA2 que libere o acesso. O teste abaixo diz exatamente qual é o caso.

Temperatura

O ideal da carga é -18 °C. O alarme falado dispara quando um sensor monitorado atinge o limite abaixo.

Quais sensores valem por veículo

Alguns caminhões têm sensor de ambiente ou de cabine, que marca 20 °C sem que haja problema nenhum na carga. Desmarque os sensores que não são do baú: eles continuam aparecendo no card, mas param de disparar o alarme.

Backup

Os dados do painel ficam salvos no navegador deste computador. Use o backup para levar tudo (viagens, entregas, usuários e configurações) para outra máquina ou para não perder nada.
